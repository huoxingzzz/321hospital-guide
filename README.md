## 本地预览

直接双击 `index.html` 用浏览器打开即可；或在目录下运行任意静态服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 上传到 GitHub

在本目录（hospital-guide/）下打开终端：

```bash
git init
git add .
git commit -m "山二医见习医院一览 by VIVI"
git branch -M main
```

1. 在 GitHub 上新建一个仓库（例如 `hospital-guide`），**不要**勾选自动生成 README
2. 按页面提示关联远程仓库并推送：

```bash
git remote add origin https://github.com/<你的用户名>/hospital-guide.git
git push -u origin main
```

## 开启 GitHub Pages（免费获得公开访问链接）

1. 进入仓库页面 → **Settings** → 左侧 **Pages**
2. **Build and deployment** → Source 选 **Deploy from a branch**
3. Branch 选 `main` / `(root)`，点击 **Save**
4. 等待 1~2 分钟，顶部会出现访问地址：
   `https://<你的用户名>.github.io/hospital-guide/`

> 仓库需为 Public（免费账户 Private 仓库无法使用 Pages）。
